How to use

  1. Type your initials, then choose a sheet: ra_impacts.csv, ra_empty.csv or ra_typing.csv.
  2. Read the post on the left (already in English). On the right, compare what the AI extracted and answer each question.
  3. Keys: Y/N answer the next unanswered yes/no question, →/← move between rows.
  4. Your answers save in this browser as you go. When done (or before closing), click Save CSV and send the file back.

Works offline. Nothing is uploaded anywhere. Full instructions: docs/RA_GUIDE.md.
